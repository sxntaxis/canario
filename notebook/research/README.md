# Research

ActaKit uses **source Books plus transversal ledgers** for research that can affect durable architecture.

A source Book studies one coherent external object — a standard, project, system, institution, or lineage — using as many primary/secondary URLs as that object actually requires. It is **not** one Book per web page.

Cross-source conclusions are made only in a synthesis package after source Books exist.

See `PACKAGE_PROTOCOL.md`.
